# A model kept in its design document

Read this when the model should live in the Markdown document that
explains the design, rather than in a `.qnt` beside it: reviewers then
read the prose and the spec together, and nothing tangles them by hand
(golem's lmt step and its CI check).

## How it works

A binding's `spec:` may name the document:

```yaml
spec: design/counter.md
module: counter
```

Its fenced blocks whose info string is `quint`, in document order, are
the model. Every other block (Go, shell, a diagram) is prose. A module may
span blocks, so a document can introduce the state, explain it, then add
the actions and the properties below their explanations.

Loading the binding writes the model to the `.qnt` of the same name
beside the document (`design/counter.qnt`), so plain quint, `quint
verify` and generated replay modules read it as any other model. That
file:

- starts with `// Code generated by gotogether from counter.md; DO NOT
  EDIT`, then the document's SHA-256;
- ends with a map from each of its lines to the document's;
- is rewritten only when the document changes, and never replaces a file
  of that name that gotogether did not generate (Load refuses, naming the
  fix: rename one of them).

`gotogether tangle design/counter.md` writes it without a binding.

## Positions are the document's

Every position quint reports in the generated file is reported at the
document's line: a typecheck error (`counter.md:23:22: [QNT404] Name
'MAXX' not found`), lint's findings, and positions in `simulate`'s and
`validate`'s reports. A failing invariant names the line it is defined
on:

```
  FAIL    belowMax (design/counter.md:23): the model should guarantee it, ...
  invariant belowMax (design/counter.md:23): FAIL
```

`simulate -json` gives each check's `source` (`"design/counter.md:23"`)
for scripts. The same `source` is given for a plain `.qnt` model's checks,
at the `.qnt`'s line.

## Checked in or not

Either way works:

- **Generated only.** Ignore the `.qnt` (`.gitignore`): every load writes
  it, so it is never stale.
- **Checked in**, for readers without gotogether, or for `quint` runs in
  CI. Then run `gotogether tangle -check design/*.md` in CI: it exits 1
  when a checked-in `.qnt` is missing or was generated from another
  version of its document, and names the command that fixes it.

  Run it first, before anything loads the binding: loading a binding
  writes the `.qnt` (simulate, validate, lint, a test's checks), so a
  check after one finds it fresh. In CI, in this order:

  ```sh
  gotogether tangle -check design/*.md   # 1: missing or stale
  gotogether simulate -binding design/contract.binding.yaml
  go test ./...                           # and every other load
  ```

  `tangle -check` exits 1 for anything it finds wrong with a document's
  `.qnt` (missing, stale, hand-written, or a document it cannot tangle),
  and 2 for a bad invocation (no document, or one that is not `.md`).
  `tangle` without `-check` writes, and exits 2 when it would overwrite a
  hand-written `.qnt` of the generated name: it refuses and keeps it.
  An edit of the document's prose changes its digest and line map too,
  so the model is stale after it: a CI control for a stale artifact
  edits the document, not the generated file.

  A design matrix in the document (`simulate -matrix -write-matrix
  design.md`) changes the document too: when its `.qnt` was current, the
  writer writes it again, so the two stay in step and `tangle -check`
  still passes; a `.qnt` already stale or missing is left for it to
  report. In CI, check the table without writing it: `simulate -matrix
  -graph -check-matrix design.md` exits 1 when the document's table is
  not the checker's (and with the matrix's own exit otherwise), and
  writes nothing.

## Results

| Report line | What it means | Do next |
|---|---|---|
| `no ```quint block` | the document has no fenced block with info string `quint` | mark the model's blocks ```` ```quint ```` |
| `a fenced block is never closed` | a fence opened at the line named has no closing fence | close it with the same fence |
| `not generated by gotogether: it would be overwritten` | a hand-written `.qnt` has the generated file's name | rename the document or the file |
| `stale: generated from another version of` | `tangle -check` found a checked-in `.qnt` older than its document | `gotogether tangle doc.md`, and commit it |
