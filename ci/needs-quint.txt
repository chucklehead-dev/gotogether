# Released by:
#   size         its compiled model is over the 1 MB a checked-in one may take,
#                gzipped (none is now: the largest, edgepublish's, is 0.78 MB)
#   Q1 connect   connect generates its traces with quint run (Q1: quint run's
#                simulation in Go)
#   Q2           the test writes a model or a binding at run time, which only
#                a Go front end compiles (Q2)
#   checker      the test builds quint's checker itself (validate.NewChecker,
#                the CLI's check and replay): validate.NewCompiledChecker, or
#                Q2, would release it
#   quint run    the test runs quint run on a module of its own (the rules'
#                folds against the read models' selections, testdata/*.qnt):
#                a gotogether.mbt/1 of it and the Go evaluator's simulation
#                (Q1) would release it
#   fragment     a run the Go evaluator cannot decide (a fold over more than
#                10 elements whose operator it cannot show commutes) is no
#                verdict by the compiled model: the evaluator's whole
#                fragment (Q1) would release it
#   real         a real tier's test (RAFTKV_REAL, toxiproxy): not run here;
#                its checks are the same RequireModel's once tried
#   veil         a proof by induction (qtest.Inductive), quint's Veil backend
#                in Lean: nothing of the Go evaluator would release it (not
#                done, skipped, without quint 0.35 and Veil)
