# What still needs quint among the examples (ROADMAP Q0), one line each:
#   <binding> | <released by> | <why>             a binding with no compiled model
#   <package dir> <Test> | <released by> | <why>  a test, in a module that keeps
#                                                 one, left on RequireQuint or Model
# The rest is found, not listed: ci/compiled-examples.sh checks every
# examples/**/*.model.json current (compile -check, where quint is) and runs
# every example test calling qtest.RequireModel with quint off PATH.
# internal/exampleapps' TestCompiledModels fails when this file and the
# examples disagree: a binding with neither a model nor a line, a line for a
# binding that has one or a test moved to RequireModel, a model over 1 MB.
#
# Released by:
#   size         its compiled model is over the 1 MB a checked-in one may take
#                (mostly quint's IR, which compresses about twenty-fold): the
#                maintainer's decision, a compact artifact or a larger budget
#   Q1 connect   connect generates its traces with quint run (Q1: quint run's
#                simulation in Go)
#   Q2           the test writes a model or a binding at run time, which only
#                a Go front end compiles (Q2)
#   checker      the test builds quint's checker itself (validate.NewChecker,
#                the CLI's check and replay): validate.NewCompiledChecker, or
#                Q2, would release it
#   real         a real tier's test (RAFTKV_REAL, toxiproxy): not run here;
#                its checks are the same RequireModel's once tried
